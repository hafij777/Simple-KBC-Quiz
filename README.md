# Simple-KBC-Quiz

A simple beginner-friendly quiz game inspired by the famous Indian game show **Kaun Banega Crorepati (KBC)**.

In this game, you will be asked multiple-choice questions.  
For every correct answer, you will win **$100,000** virtual prize money.

## Features

- Multiple choice questions (a, b, c, d)
- $100,000 prize money for each correct answer
- Total prize money shown at the end
- Beginner-friendly Python code
- Easy to add more questions

## Requirements

- Python 3

## How to Run

1. Download or clone this repository
2. Open the folder in any code editor (VS Code, PyCharm, etc.)
3. Run the Python file:

```bash
python main.py
